# DLH Shell

This repository contains shell and Linux command-line practice projects.

## Project Structure

| Folder | Description |
|---|---|
| [permissions](./permissions) | Shell permission tasks, including user switching, file ownership, groups, and access rights |

## Main Topics

- Shell basics
- Linux commands
- File and directory navigation
- File permissions
- Users and groups
- Ownership
- Executable permissions
- Permission notation such as `r`, `w`, and `x`

## Tools Used

- Terminal
- Linux shell
- Git
- GitHub
- Visual Studio Code

## Learning Goal

The goal of this repository is to build confidence using the command line and understanding Linux file permissions.
